# Thread Summary

Summarize the available thread. Use /sss if available, but follow this structure:

- Start with `## 🧵 Summary` and exactly one distilled sentence, leading with the most recently worked-on topic.
- Only if necessary, add `### 📋 Details` with short bullets for important context, decisions, unresolved questions, or next steps.
- Use appropriate emojis on any additional headings so they are easy to scan.
- Keep it short and factual. Distinguish completed work from plans. Output only the summary.
